# Мишкина Мышь (Mishkinamish)

Голосовое управление курсором мыши через звуковые команды (гласные И, У, О, Э и короткие согласные К, Ч).

## Назначение

Программа распознаёт 6 звуков русского языка в реальном времени через микрофон:
- **И** (0) — движение влево
- **У** (1) — движение вниз
- **О** (2) — движение вправо
- **Э** (3) — движение вверх
- **К** (4) — короткий клик (нажатие+отпускание)
- **Ч** (5) — длительное нажатие (только нажатие)

На основе MFCC-признаков (Mel-Frequency Cepstral Coefficients) и метода гиперплоскостей звуки классифицируются, после чего эмулируется движение мыши или нажатие кнопок.

## Архитектура

```
mmish001.cpp          — Главный модуль (WinMain, оконная процедура, диалог)
InputThread           — Захват звука с микрофона через WASAPI
WorkerThread          — Обработка звука: расчёт уровня, K/Ч-детекция, MFCC
OutputThread          — Вывод звука через WASAPI (для кликов)
CopyShmopy            — DSP-обработка: pre-emphasis, Hamming, FFT, MEL, DCT
casphinx              — Расчёт MEL-спектра по таблице (наследие CMU Sphinx)
MModel                — Модель звуков: списки MFCC, гиперплоскости, сохранение/загрузка
KChFstate             — Конечный автомат для детекции коротких звуков К/Ч
Indicators            — Отрисовка индикаторов уровня и звуков, движение/клик мыши
ClickSound            — Генерация звука клика мыши
WAVLoader             — Загрузка WAV-файлов (16 кГц, моно, 16 бит)
WAVDump               — Дамп звука в WAV-файл
GZLists               — Шаблоны двунаправленных списков (GZSList, GZTList)
```

## Потоки

1. **InputThread** — поток захвата с микрофона (WASAPI, shared mode). Конвертирует формат устройства в 16 кГц/моно/16 бит, передаёт данные в WorkerThread.
2. **WorkerThread** — основной обрабатывающий поток. Получает буферы от InputThread, вычисляет уровень сигнала, детектирует короткие звуки (K/Ч), вычисляет MFCC и проверяет совпадение с моделью.
3. **OutputThread** — поток вывода звука. Проигрывает обработанный звук (с возможными кликами) на устройство воспроизведения.

## Обработка звука (CopyShmopy)

1. **Наложение со сдвигом 160** — входной буфер (205 отсчётов) копируется в двойной буфер; обработка идёт блоками по 410 отсчётов со сдвигом 160 (OLA — overlap-add).
2. **Pre-emphasis** — фильтр `y[n] = x[n] - 0.97 * x[n-1]`.
3. **Окно Хэмминга** — `w[i] = 0.53836 - 0.46164 * cos(2π * i / 204)`.
4. **FFT (512 точек)** — вычисление power spectrum через Intel IPP или software fallback.
5. **MEL-спектр (40 фильтров)** — табличное умножение на предрассчитанные веса (из CMU Sphinx).
6. **Log + DCT-II** — логарифм и дискретное косинусное преобразование → 13 MFCC.
7. **Интеграция с наложением** — выходной сигнал собирается по схеме 90-70-90.

## Модель (MModel)

Хранит эталонные MFCC для 6 звуков + тишины. Использует метод разделяющих гиперплоскостей (гиперплоскость = точка средней + направление между центрами звуков). Классификация: скалярное произведение `(test - base_point) · direction` должно быть ≤ 0 для всех соседних звуков.

Файлы модели имеют сигнатуру `MM00x` и расширение `.MM1`. Версии:
- MM001 — базовый формат
- MM002 — добавлен флаг `flag_kc_anytime`
- MM003 — добавлены привязки клавиш
- MM004 — добавлены флаги повтора (repeat)
- MM005 — добавлены флаги залипания (toggle)

## Конечный автомат К/Ч (KChFstate)

Состояния детекции коротких звуков:
- **0** — ожидание тишины (уровень стабилен 20+ фреймов)
- **1** — готовность к приёму всплеска
- **2** — всплеск (звук) — если длится >8 фреймов — сброс
- **3** — пауза после звука — если пауза >12 фреймов — К/Ч подтверждён; если новый всплеск раньше — сброс

Упрощённый режим (`flag_kc_anytime`) — разрешает К/Ч в любом фрейме с интервалом 20 фреймов.

## Тренировка

Для каждого из 6 звуков необходимо произнести его в микрофон ~300 раз. Программа автоматически записывает MFCC, когда уровень сигнала превышает уровень тишины. После тренировки модель сохраняется в `default.MM1`.

## Сборка

**Требования:**
- Visual Studio (MSBuild)
- Intel oneAPI (IPP — Intel Integrated Performance Primitives)
- Windows SDK

**Сборка:**
```
build.bat
```

Или открыть `mishkinamish.sln` в Visual Studio.

**Проверка:**
```
python check.py
```

## Управление

- Кнопка **Запустить/Стоп** — активация/деактивация управления мышью
- **Alt+F5** — горячая клавиша для той же функции
- Выбор микрофона из списка (или чтение из WAV-файла)
- Кнопки **Тренировать** — обучение каждому из 6 звуков
- **Сохранить** — сохранение модели в `default.MM1`
- Чекбоксы **К/Ч в любое время** — упрощённый режим
- Чекбоксы **Повтор/Залипание** — режимы клавиш для направлений
- **WAV-дамп** — запись входящего звука в файл

## Индикаторы

- Зелёная шкала — уровень громкости (8 делений)
- Красный сектор — перегрузка
- Квадратики у букв — зелёный (звук распознан), красный (не вовремя)
- При тренировке: красная полоса "Тишина в студии", затем progress bar

## Зависимости

- Intel IPP (ipps, ippcore) — FFT и DCT
- Windows WASAPI — захват и воспроизведение звука
- GDI — отрисовка индикаторов
- OpenGL — отладочная 3D-визуализация (в режиме MM_SUPERUSER)
